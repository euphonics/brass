# Brass 0.3.0

Requires Obsidian 1.13.7 or later. Still a beta: keep backups of your
screenplays, and please
[report problems](https://github.com/euphonics/brass/issues).

## Highlights

- **Placeholders panel.** The command **Show placeholders** lists every
  `$placeholder` in the note and its project folder, with each place it's
  used; click a line to go there.
- **Hide synopses.** Turn off **Show synopses** (Look of the page) and
  synopsis lines (`= ...`) are hidden until the cursor is on one. The
  slugline or heading above shows 📝; click it to see the synopsis.
- **Boneyard keeps your headings.** Text moved to the boneyard lands under
  the same headings it had in the script (`# Act 1`, `## The heist`),
  added to the boneyard note in the script's order when they aren't there
  yet.
- **`+` names everywhere.** The `+` character list works in dialogue,
  wrylies, sluglines and cues too, not only action. Sluglines and cues get
  the name in capitals.
- **Lists close when they're no use**, like Fade In: once the only item is
  what you've typed (`FIONA`, `(beat)`), the list goes away and Enter does
  its usual job.
- **Delete a thread everywhere** from the Threads panel (type YES to
  confirm), and `&&` now gives `[&]` with the cursor inside.
- **Phone toolbar.** A 🔄 Convert button turns the next element button
  into "change this line" instead of "start a new one". It floats above
  the row at the right. The Slug button opens the scene type list in the
  editor. The bar is plainer, just the emoji, and no longer slides when
  nudged.

## Fixes

- Text after a boneyard (`/* ... */`) is no longer shown in italics.
- Enter inside a code block adds one line, even before the closing fence
  is typed (it used to add an empty line each time).
- `TYLER (30) walks in.` stays action; only `TYLER (30s)` then Enter makes
  a cue.
- Enter picks a `+` name on a bullet line; Backspace joins a thread-only
  line to the action above; the first boneyard picker says why it opened.

The full list is in the
[changelog](https://github.com/euphonics/brass/blob/main/CHANGELOG.md).

## Not yet checked on a real phone

The phone toolbar changes were tested in Obsidian's mobile layout on a
computer, not yet on a physical phone. Please report anything odd about
its position, the keyboard or scrolling.

## Updating by hand

Put `main.js`, `manifest.json` and `styles.css` from below in
`.obsidian/plugins/brass/`, then turn on Brass.
