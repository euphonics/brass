# Scribidian 0.1.0 — First beta

Requires Obsidian 1.13.7 or later.

**This is a beta.** Scribidian has so far been tested by one writer. Expect
rough edges, keep backups of your screenplays, and please
[report problems](https://github.com/euphonics/scribidian/issues). Version
1.0.0 will follow once more people have used it.

Scribidian is derived from
[First Draft](https://github.com/grobmeier/firstdraft) 0.13.1 by Christian
Grobmeier (Apache License 2.0). It keeps First Draft's parser, exports,
palette, character pages, projects and scene workspace, and adds a set of
writing features on top.

## Moving from First Draft

- Scribidian has its own plugin ID (`scribidian`), so it installs next to
  First Draft rather than replacing it. Do not enable both at the same time.
- New character and project notes are marked with a `scribidian:` property.
  Notes marked with First Draft's `firstdraft:` property keep working and are
  not rewritten.
- Settings and hotkeys do not carry over automatically. To keep your settings,
  copy `data.json` from `.obsidian/plugins/firstdraft/` into
  `.obsidian/plugins/scribidian/` before enabling Scribidian.

## What Scribidian adds

**Screenplay layout in the editor** (optional, display only)

- Each element is indented and aligned as it prints, in a 60-character column
  that holds under themes such as Minimal.
- Titles are bold and centred; forced sluglines hide the leading `.` and
  sluglines are bold; `> centred <` text hides both markers.
- Dual dialogue (`^`) is drawn side by side.
- Suggestion lists and the cursor line up with the element being typed.
- Screenplay font setting with a list of installed fonts (Courier fonts first).
- Bottom typing margin, and an optional current-page indicator.

**Smart Tab and Enter**

- Tab moves between action, character, parenthetical, dialogue, slugline and
  transition; mid-speech it inserts a wryly; mid-line elsewhere it does
  nothing rather than insert a tab character.
- Enter after a scene heading, transition, dialogue or action paragraph starts
  the next element with the right spacing; Shift+Enter breaks a line.
- Shift+Tab or Escape turns a pending cue line back into action.
- Sluglines are uppercased as you move on; the first letter of each line can
  be capitalised (on by default).

**Suggestions**

- Scene types, locations (including forced `.` headings), times of day and
  slug modifiers such as `(FLASHBACK)`, with preferred modifiers in settings.
- Character list ordered by turn so dialogue alternates; extensions open on
  `JEN(`; transitions on `>`.

**Commands and settings**

- "Set line to …" commands for each element, for use with hotkeys.
- Export to clean Fountain, with a choice of what to remove.
- Character pages named after the project, with a template from your
  Templates folder and the first name as an alias.
- Render ` ```fountain ` code blocks with screenplay formatting.
- Grouped, searchable settings with a button to jump to the plugin's hotkeys.
