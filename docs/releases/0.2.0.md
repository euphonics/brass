# Brass 0.2.0

**Scribidian is now Brass**, named after the brass brads that bind a
script. Requires Obsidian 1.13.7 or later. Still a beta: keep backups of
your screenplays, and please
[report problems](https://github.com/euphonics/brass/issues).

## Switching from Scribidian

The plugin has a new ID (`brass`) and a new home: **github.com/euphonics/brass**.

1. In BRAT, add the beta plugin `euphonics/brass` (BRAT does not follow the
   rename by itself).
2. Turn on **Brass** under Community plugins.

On its first start Brass copies your Scribidian settings and custom
hotkeys, turns Scribidian off (both would claim `.fountain` files) and says
so in a notice. Panels that were open under the old name (Scenes, Threads)
need to be opened once more. You can then remove Scribidian.

Notes marked `scribidian:` keep working. To rename the property, open a
script and run **Convert Scribidian properties in this folder**: it
changes the script, the notes in its folder and the character folder,
never the whole vault.

## Highlights

- **Phone toolbar.** On phones and tablets, a script gets a row of buttons
  above the keyboard toolbar: ⬅️ Smart Tab back, 🎬 new scene, 🏃 action,
  🗣️ character and ➡️ Smart Tab. The new **Phone toolbar** settings
  section turns it off, picks and orders the buttons (✂️ transition,
  🤔 wryly, 📍 mini slug, 🎙️ extension, 🎯 centered and 👥 dual dialogue
  are there too), switches the labels between emoji and short words, and
  can make a button convert the line you're on instead of starting a new
  one. Never shown on a computer or in a plain note.
- **Courier Prime on every device.** Brass brings its own copy, so scripts
  and the page preview use it on phones too.
- **Mini slugs and extensions.** New scene offers **Mini slug (.)**
  (`.KITCHEN`), and Character offers **With extension (V.O.)…**.
- **Scene buttons work with boneyards.** A boneyard (`/* */`) anywhere in a
  script used to turn off Synopsis, Up, Down and Move; now only one that
  never closes does, and a boneyard moves with its scene. A grayed-out
  button says why when tapped.
- **Time suggestions in their usual order**: DAY, NIGHT, MORNING… come
  first again, unless your script uses another time more.
- **A logo**: the brass brad, on the Scenes panel and its ribbon button.
- **Settings in folding sections**, from what every writer needs to the
  niche, each with its own count of changes and a reset button.
- **Threads** can be turned off, and `&&` starts one. Project notes
  (outline, notes in the script's folder) get `&&`, `$` colors and
  character name suggestions too.

The full list is in the
[changelog](https://github.com/euphonics/brass/blob/main/CHANGELOG.md).

## Not yet checked on a real phone

The phone toolbar was tested in Obsidian's mobile layout on a computer, not
yet on a physical phone. Please report anything odd about its position,
the keyboard or scrolling.

## Updating by hand

Put `main.js`, `manifest.json` and `styles.css` from below in
`.obsidian/plugins/brass/`, then turn on Brass.
